# Story 9.4: Release / Go-Live Checklist

## Status
Open — owner checklist. All engineering it depends on (9.1–9.3, plus Epics 7–8 packaging) is
done; this story is the human steps to actually start selling.

## Story
**As the** owner,
**I want** one ordered checklist that turns the finished build into a live, paid product,
**so that** going live is a deliberate switch-flip I can run when I feel ready — not a scramble.

## Acceptance Criteria
1. **Single source of truth.** A checklist captures every go-live step in order: build
   verification, licensing keys, code-signing cert, storefront + webhook, purchase URL, publish,
   and launch hygiene. → `docs/RELEASE-CHECKLIST.md`.
2. **No hidden code work.** Each item is an owner action; anything needing code is called out
   explicitly (only `PURCHASE_URL` + an optional production-keypair regen).
3. **Verification gates.** The checklist includes the clean-VM pass and a free/premium on-machine
   pass before publishing.
4. **Carry-overs folded in.** Open items from Epics 7–8 (signing cert, clean-VM run, non-Corsair
   RGB check) are surfaced so nothing is lost.

## Notes
This story intentionally has no automated tests — it's a release runbook. The checklist lives at
`docs/RELEASE-CHECKLIST.md`; monetization specifics (storefront, webhook, pricing, key secrecy)
are in `docs/MONETIZATION.md`.

The two hard prerequisites that are *not* in the repo's control:
- a **code-signing certificate** (Story 7.4 carry-over) — required before any public download;
- a **storefront account + fulfillment webhook** holding the private signing key as a secret.
